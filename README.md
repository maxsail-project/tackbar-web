# TackBar Web

Public website for **TackBar**.

TackBar is an open-source project for dinghy sailors focused on collaborative post-sailing debriefing: bringing sailing sessions together to compare what happened on the water, discuss it, and learn from it.

**TackBar**

*Sail. Debrief. Learn.*

*We sail. We debate it over beers. We learn.*

## Pilot

TackBar is currently in an experimental pilot phase.

Sailors interested in participating can contact:

**maxsail.project@gmail.com**

Current pilot data support includes Vakaros exports in:

- `.csv`
- `.csv.gz`

Additional sailing devices and data sources will be added progressively.

## Open source

TackBar is an open-source project.

The website code in this repository is released under the MIT License.

Open-source refers to the project code. Personal sailing data, GPS tracks and participant information are not published as open data.
